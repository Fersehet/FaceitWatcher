2. Kurz gesagt

Diese Website ist eine reine Informationsseite. Es gibt keine Anmeldung, kein Kontaktformular, keine Cookies, kein Tracking und keine Werbung. Schriften und Bilder werden vom eigenen Server geladen.

3. Hosting und Server-Logfiles

Die Website läuft auf einem privat betriebenen Server in Deutschland. Davor sitzt ein Reverse-Proxy (Nginx Proxy Manager), der die verschlüsselte Verbindung (HTTPS) herstellt. Bei jedem Aufruf verarbeitet der Server technisch notwendige Daten: IP-Adresse, Datum und Uhrzeit, aufgerufene Seite, übertragene Datenmenge, Referrer sowie Browser und Betriebssystem.

Diese Daten werden nur genutzt, um die Seite auszuliefern und die Sicherheit des Servers zu gewährleisten (zum Beispiel um Angriffe zu erkennen). Rechtsgrundlage ist Art. 6 Abs. 1 lit. f DSGVO. Unser berechtigtes Interesse liegt im sicheren und stabilen Betrieb. Die Logfiles werden nach spätestens 14 Tagen gelöscht. Eine Zusammenführung mit anderen Daten findet nicht statt.

4. Verschlüsselung

Die Seite wird über HTTPS ausgeliefert. Das Zertifikat stammt von Let’s Encrypt. Dabei werden keine Daten der Besucher an Let’s Encrypt übertragen.

5. Schriften

Alle Schriften (Chakra Petch, Barlow, JetBrains Mono, Play) sind lokal auf dem Server gespeichert. Beim Besuch wird keine Verbindung zu Google oder anderen Schriftanbietern aufgebaut.

6. Overlay-Vorschau und Faceit-Daten

Die Vorschau auf der Startseite zeigt öffentlich verfügbare Spielstatistiken des Betreibers von der Plattform FACEIT. Diese Daten fragt unser Server bei FACEIT ab und speichert sie zwischen. Profil- und Levelbilder liefert ebenfalls unser Server aus. Dein Browser verbindet sich dabei nicht mit FACEIT, und es werden keine Daten von dir an FACEIT übermittelt.

7. Externe Links

Die Seite verlinkt auf GitHub und FACEIT. Erst wenn du einen solchen Link anklickst, verlässt du diese Website, und es gelten die Datenschutzbestimmungen des jeweiligen Anbieters. Vorher werden keine Daten an diese Anbieter übertragen.
